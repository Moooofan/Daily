📱 Daily 響應式設計測試

測試說明

本頁面用於測試 Daily 應用在不同螢幕尺寸下的顯示效果。您可以:

  • 在桌面瀏覽器中調整視窗大小查看響應式效果
  • 使用瀏覽器的開發者工具切換裝置模擬
  • 在實際手機、平板上訪問 http://localhost:5001 查看效果

🎯 響應式斷點

桌面版 (> 768px)

  • 雙欄佈局
  • 完整功能
  • 滑鼠懸停效果

平板版 (≤ 768px)

  • 單欄佈局
  • 字體縮小
  • 觸控友好

手機版 (≤ 480px)

  • 緊湊佈局
  • 大號按鈕
  • 分頁換行

小手機 (≤ 360px)

  • 最小間距
  • 垂直排列
  • 極簡字體
🖥️ 桌面版 (1200px)
📱 平板版 (768px)
📱 手機版 (375px)

✨ 手機版特色功能

  • 觸控優化: 所有按鈕至少 44×44px,符合觸控標準
  • 自適應佈局: 根據螢幕寬度自動調整排列方式
  • 字體縮放: 在小螢幕上自動縮小字體保持可讀性
  • 待辦分頁換行: 在小螢幕上自動換行避免擁擠
  • 模態框優化: 在手機上佔據 90% 寬度
  • 橫向支援: 橫向模式下優化佈局

📲 如何在手機上訪問

  1. 確保手機和電腦在同一個 Wi-Fi 網路
  2. 查看終端中顯示的 IP 位址,例如: http://192.168.0.41:5001
  3. 在手機瀏覽器輸入該網址
  4. 享受原生 App 般的體驗!
